## [0.1.0] — 2026-05-26

Initial OSS release.

### Added

- 7-step risk assessment wizard (TEAR + ALARP)
- Asset & relationship graph
- Site map with risk visualization
- PDF report export
- Multi-user with 5 roles (Admin / Editor / Reviewer / Viewer / Auditor)
- Template library (NIS2, ISO 27001)
- Docker Compose quick start
- Demo instance: https://demo.grace-ps.io
